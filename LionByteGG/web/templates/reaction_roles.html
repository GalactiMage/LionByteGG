How to Create Reaction Roles

1

Use the Setup Command

In Discord, use /setup-reaction-roles to create a new reaction role panel.

2

Configure Roles

Add emoji-role pairs to the panel. Each emoji will assign a specific role when clicked.

3

Members React

Members click the emoji to receive the role. Click again to remove the role.
