How VC Generators Work

Join to Create

When a user joins a generator VC, a new temporary voice channel is created for them.

Owner Controls

The channel creator becomes the owner and can manage permissions and settings.

Auto Cleanup

Empty channels are automatically deleted to keep the server clean.

Tryout Mode

Tryout generators create private channels for team tryouts and practices.

Setup Commands

/setup_vc_generator

Create a new normal VC generator channel

/setup_tryout_vc

Create a new tryout VC generator channel

/list_vc_generators
